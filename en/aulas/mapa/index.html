The updates map: what changed and what you already have

Many people talk about "Claude Code 2.0," but no one explains what changed or what already works in Brazil. In this lesson, you’ll see the 13 updates in six groups, learn what each one requires (app, plan, version), and check in your own Claude what you already have, what you don’t, and what’s on the waitlist.

  1. 1/7

    Organize

    Organize your work. Conversations appear in sections in the sidebar, one for each project. Side chat answers a quick question without adding it to the main conversation. Split view shows two conversations side by side in the same window.

  2. 2/7

    Delegate

    A conversation splits a big job among helpers, called subagents. Each one handles a part and returns the result, and the conversation reviews and combines everything. Many people call these “nested sessions,” but the official name is subagent.

  3. 3/7

    Apps

    Claude uses computer programs for you (computer use) and websites (the app’s built-in browser). Computer use is in preview (a test version that may still change), on Mac and Windows, for Pro, Max, and Ultra plans, and is turned off by default. Lesson 4.

  4. 4/7

    Away

    Keep up with work from your phone (Remote Control, with your computer on) and send work to the cloud (Projects, which keeps going with your computer off). Projects is in beta (being tested and rolling out gradually) and requires joining a waitlist: you sign up and wait for access on your account. Claude Duet brings the next task to you, but it is currently available only in the US, with a waitlist. Lesson 5.

  5. 5/7

    Deliver

    Turn your work into something someone else can open: slides, artwork, a data dashboard, an animated video (Motion), or a document shared by link. Slides and Design are available on all plans; Dashboards is in beta; Motion is in beta and available only on Team and Enterprise plans.

  6. 6/7

    Customize

    Make Claude work your way. Slash commands are shortcuts you type with /, like /rewind and /recap. Mods change how Claude Code looks and behaves (a bar, a notice, a new command) and require version 2.1.287 or later.

  7. 7/7

    Your map

    Organize, delegate, use apps and websites, work away from your computer, deliver, and customize. The next six lessons follow that order, using Carla’s work as an example throughout.

02 · Before you try them: four things to check

What “Claude Code 2.0” means and what each new feature requires.

1. The nickname

Claude Code is Anthropic’s assistant that works with your files and computer, not just in chat. “Claude Code 2.0” is the nickname many people gave to the bundle of new features in its 2.1.x versions.

There’s no “2.0” button. And this isn’t Claude 2, an older Anthropic model: we’re talking about Claude Code versions 2.1.x.

RememberWhen someone says “Claude Code 2.0,” think: new features in versions 2.1.x.

2. The app

Almost all the new features are in the Code tab of the Claude app for Mac and Windows. The Code tab is where Claude works in a folder on your computer.

The app doesn’t run on Linux. Use Claude Code in the terminal (the command window). There, slash commands, side chat with /btw, and Remote Control work.

CarlaShe uses a Windows laptop. She’ll do almost everything in the app’s Code tab, without opening the terminal.

3. The plan

The new features require a paid plan (Pro, Max, Ultra, Team, or Enterprise). What you see depends on your plan.

Computer use isn’t available on Team or Enterprise. Motion, on the other hand, is only available on Team and Enterprise. Projects and Claude Duet require joining a waitlist, and Duet is currently available only in the U.S.

CarlaShe has Pro. She already knows Motion won’t appear for her and Duet will have to wait.

4. Version

A lot depends on the version you have installed. Update the app before you try anything: a feature that “doesn’t show up” usually means the app is out of date.

If you only use the app, you don’t need to see a version number: just note the date you updated it. If you have the terminal (optional), you can run claude --version and check the number, which starts with 2.1. The mods require version 2.1.287 or newer.

A practical ruleBefore you say “I don’t have it,” update and check again.

05 · Practice: your map

Fifteen minutes. Without this, the next lessons become guesswork.

E1 · Update the app

5 min

Update the Claude app and note today’s date. If you also use Claude Code in the terminal (optional), run claude --version and note the number.

Done when: you wrote down “app updated on [date]” (or, in the terminal, a number starting with 2.1).

E2 · Make the list with Claude

5 min

Paste the “make my list” prompt into Claude (in the app, on the Code tab, or at claude.ai), with your system, plan, and version.

Done when: Claude sorted the 13 features into HAVE, DON’T HAVE, and WAITLIST.

E3 · Check on screen

5 min

Check in the app the items Claude marked “check on screen” (Projects in the sidebar, computer use in settings). Update the list in the checker above and save it with the “Download the file” button: it downloads the ready-to-use minha-lista.txt file.

Done when: the checker above says “OK: all 5 fields are filled in” (for Version, enter the number or the date you updated the app) and each of the 13 features appears in one of the three lines.
