Lesson 4 · 16 min

Apps and websites: Claude uses them for you, following your rules

Not every program or website has an easy way to automate it. Now Claude can use an app on your computer (computer use) or a website through the browser built into the app. Being able to do something doesn’t mean you should do everything. In this lesson, you’ll allow only what’s needed and run a read-only task on one of your websites, checking that nothing changed.

Start the lesson

In this lesson, you’ll

  1. 1What computer use is and where it works
  2. 2Open the built-in browser and log in yourself
  3. 3The rules in between: read-only and ask first
  4. 4Check before and after that nothing changed on the website

Goal: Let Claude use computer programs and websites for you, allowing only what’s needed.

01 · Two paths, the same rules

Tap or click each part.

If you’re unsure, start with the website, read-only. It’s the easiest way to check.

Computer program → computer use. Website → built-in browser. The rules apply to both. Both are only available in the Mac and Windows apps; there is no app for Linux.

02 · Turn on each option

Four steps. Click each one.

1. Browser

In the Claude app (Code tab), press Cmd + Shift + B on Mac (Ctrl + Shift + B on Windows). A browser opens inside the app.

Go to the website and sign in yourself. Then describe the task in the conversation.

Golden ruleNever put your password in the conversation. You type it into the browser yourself.

2. Computer use

Turn on computer use in the app settings (Settings). If you can’t find it, ask Claude in the Code tab: "where do I turn on computer use in this app?". On Mac, the system asks for two permissions: Accessibility (to click and type) and Screen Recording (to see the screen).

When Claude asks to use an app, allow only the app for that task.

Good usesOrganize Desktop screenshots into folders by month. Export a video in an editor that has no other automation.

3. Where it works

The built-in browser is in the Mac and Windows apps. Computer use is in preview on Mac and Windows, with Pro, Max, and Ultra plans; it isn’t available for Team and Enterprise.

There is no app for Linux: Claude Code runs in the terminal, without these two features. Plans and availability can change, so check in your app.

RememberWith computer use, browsers are for viewing only. Use websites in the built-in browser.

4. Read-only

Before the task, note a sign that would change if something were edited: the number of posts, drafts, or the date of the last edit.

After the task, check that same sign. If it’s the same, nothing changed. Also keep the app updated before opening websites.

Ready-to-use sentenceDon’t publish, reply, delete, or change anything on the website. If something needs to change, stop and ask me.

  2. Why does VLOOKUP return #N/A? (5 posts)

  1. Before: note the number of posts in the community and the date of your last post.
  2. After: check again. Both should be the same.
  3. Open community/questions.md and click a link: the post exists and includes the question.
  4. For screenshots: compare the number of files before and after. They should match.
  • Request without limits: "check the community and take care of whatever needs doing" lets Claude reply to and delete posts.
  • Password in the conversation: you sign in yourself in the browser.

  • Out-of-date app: update it before opening websites.

    05 · Practice: a read-only task on one of your sites

    You need the Claude app on Mac or Windows. There’s no app for Linux: do E2 by pasting the page text into a chat and asking for the same list.

    E1 · Before

    5 min

    Choose one of your sites: a channel, store, blog, or community. In the app, open the built-in browser (Cmd + Shift + B on Mac, Ctrl + Shift + B on Windows) and log in yourself. Write down one thing that would change if anything were edited: the number of posts or drafts, or the date of the last edit.

    Done when: you’re logged in through the app’s browser, and you’ve written down the thing you’re tracking on paper or in a file.

    E2 · The task

    15 min

    Adapt the block "Template · one of your websites" and paste it into the chat. Wait for the file and the response. Then check the thing you wrote down.

    Done when: the file with the list exists, you opened one of the links, and the thing you wrote down is the same as before.

    E3 · Computer use (optional)

    15 min

    Only if you have a Mac or Windows computer and a Pro, Max, or Ultra plan. Turn on computer use in the app settings (Settings); if you can’t find it, ask Claude where it is in this app. On Mac, allow Accessibility and Screen Recording. Count the screenshot files on your Desktop and paste the request "organize screenshots". On Windows, don’t use the mouse or keyboard until Claude is done.

    Done when: the Screenshots folder on your Desktop has one folder for each month, and the total number of files inside it matches what you counted before.
