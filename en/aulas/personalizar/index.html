Customize: slash commands, mods, and your routine

Five short commands change how Claude works: undo, see what’s taking up space in the conversation, summarize, work toward a goal, and give shorter answers. Mods change how Claude Code looks, but you should check them first. At the end, Carla picks three new things from the course and writes her routine for the week. You’ll make yours.

  2. 2/5

    Mods

    A mod is a type of plugin (add-on), which is why its menu is called /plugin. It changes how Claude Code looks and behaves: a bar showing how much of the conversation you’ve used, an alert when something finishes, or a new command. It appears in the app’s Code tab (and also in the terminal and VS Code, a code editor).

  3. 3/5

    Check

    A mod doesn’t run on its own: it can access whatever Claude Code can, including your files. So before installing, ask Claude to check what the mod does. If something goes wrong later, ask Claude to turn off the mod or use the /plugin menu. This part is optional and more technical.

  4. 4/5

    Your weekly

    No one uses thirteen new things all at once. Pick three, say what day or when you’ll use each one, and why. A week from now, replace the one that didn’t stick.

  5. 5/5

    Turn a tool into a habit

    Commands for everyday use, mods only after checking them, and a short routine with three new things.

Commands adjust the session; mods adjust Claude Code; your routine decides what you actually use.

02 · The 5 commands, with Carla’s example

Type / in the message box (in the app’s Code tab) and choose from the list. If a command doesn’t appear, update the app and check again. If it still doesn’t appear, ask Claude: "how do I use /recap in this app?". In the terminal (optional), they work the same way.

1. /rewind

Takes the conversation back to before a bad answer, as if it never happened. The shortcut is to press Esc twice.

Better than arguing with Claude: go back and ask in a different way. It rewinds the conversation; if the bad answer already changed a file, ask Claude to check the file.

CarlaShe asked only for the title of lesson 1, and Claude replied with the whole lesson. /rewind, then a new, clearer request.

2. /context

Context is everything Claude is considering in this conversation: history, files it has read, and instructions. /context shows a color-coded chart of how much space each part takes up.

A full conversation gets slower and uses more of your limit.

CarlaShe saw that three old scripts were taking up a lot of space, so she started a new session for lesson 2.

3. /recap

Gives you a one-line summary of the session right away. Useful when you come back from lunch and can’t remember where you left off.

After a few exchanges, Claude also makes this summary on its own.

4. /goal

Give Claude a clear goal, and it keeps working until it reaches it. A clear goal can be measured: "5 exercises, each with an answer," not "good exercises."

Without a measure, it doesn’t know when to stop.

5. /output-style

Changes how the responses are written. Choose concise for shorter, more direct answers.

Good for everyday use; switch back to the default style when you want a longer explanation.

04 · Mods: check before installing (optional, more technical)

You can skip this if you just want to use the app as it is. Ready-to-use examples: 18 tested mods in the inematds/inema-mods repository on GitHub. Heads up: that repository is in Portuguese, so ask Claude to explain any mod in English. GitHub is a site where people store and share code; a repository is a project folder there.

1. Update

Mods require Claude Code version 2.1.287 or later. In the app, just keep it up to date; in the terminal (optional), claude --version shows the number.

Older version: the mod won’t appear, and it’s not a problem with the mod.

2. Ask for a check

Mods aren’t isolated: they can read your files and run commands, just like Claude Code. So have Claude check first: it runs a check command (claude plugin validate) in the mod’s folder.

This check shows when the mod acts on its own (the hooks) and what it asks to use. You don’t need to understand the command: the prompt below asks for a summary in plain language.

No terminalIn the app’s Code tab, paste the prompt below: Claude will run the check itself.

3. Install or decline

Read the plain-language summary: what it reads, what it runs, and whether it uses the internet. Unsure? Don’t install it.

To install or turn off mods, type /plugin in the message box and use the menu that opens. The change takes effect when you close the menu.

4. Emergency exit

If Claude starts acting strangely after you add a mod, ask in that session: "turn off the mod [name]" or "uninstall the mod [name]". Or type /plugin in the message box and turn off the mod in the menu; it takes effect when you close the menu.

For terminal users only (optional): claude --safe-mode opens Claude Code without any customizations if it won’t open properly.
