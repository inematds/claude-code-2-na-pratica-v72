Lesson 2 · 15 min

Organize: one place per project and questions on the side

A conversation full of unrelated questions gets slow and confusing, and a huge list of conversations hides the work. Three new features fix that: project sections in the sidebar, side chat for quick questions, and split view to see two conversations side by side. In this lesson, Carla organizes her spreadsheet course using all three.

Start the lesson

In this lesson, you’ll

  1. 1One section per project in the sidebar
  2. 2Ask on the side with side chat (or /btw)
  3. 3Two conversations side by side in split view
  4. 4Keep the main conversation focused on the work

Goal: Organize your work by project and ask side questions without cluttering the main conversation.

    The main conversation is where the work happens: read the outline, write the exercises, save the file. It keeps everything that was said, and every unrelated question you add here stays in the history and weighs on future responses.

  3. 3/5

    Side chat

    A small window on the side for a quick question. It answers using what the session already knows, without using tools (it won’t open a new file or search), and this exchange stays out of the main history.

  4. 4/5

    A second conversation open beside the first in the same window. Each does different work at its own pace, and you can see both. Golden rule: never have both working on the same file.

  5. 5/5

    Each project in its own section, the main conversation focused on the work, questions in side chat, and a second task in split view.

Sections keep things organized, the main conversation handles the work, side chat answers questions, and split view shows a second task alongside it.

02 · How to use each one

Everything is in the Code tab of the Claude app (Mac and Windows). On Linux, see the last tab.

1. Sections

Update the app and open the Code tab. Conversations appear in the sidebar on the left; the idea is to keep conversations for each project together in a section named after it.

The exact place to create a section varies between app versions. If you can’t find it, ask Claude in the Code tab: "how do I create a section in the sidebar in this app?". One section per project is enough: more than that becomes another huge list.

CarlaThree sections: spreadsheet course, channel, and community. The lesson 1 conversation goes in the course section.

2. Side chat

In the middle of your work, press Cmd + ; on Mac (Ctrl + ; on Windows). Side chat opens: ask your question, read the answer, and close it.

It answers only with what the session already knows and doesn’t use tools. Use it for "what is this?", a synonym, or a calculation. For real work, go back to the main conversation.

When to use itIf the answer doesn’t need to be saved with your work, ask it in side chat.

3. Split view

In the sidebar, hold Option and click a session on Mac (Alt + click on Windows). Or right-click the session and choose Open in → Split view.

To remove a session from split view, use Cmd + Ctrl + W on Mac (Ctrl + Alt + W on Windows). Start a new session with Cmd + N on Mac (Ctrl + N on Windows).

What to put side by sideTwo different tasks, in different files. To coordinate many sessions, see the course Claude as an agent manager.

4. In the terminal

Sections and split view are part of the app. In the terminal (including on Linux), ask a question on the side with the /btw command followed by your question.

/btw works the same way: it doesn't interrupt the work or appear in the main history.

Example/btw what is VLOOKUP, in one sentence?

03 · Before the prompts: file, folder, and path

Three things that apply throughout the course. Read once.

1. .md file

The course prompts refer to files like script.md. An .md file is just plain text, like a notepad, that Claude can read and write without a special program. You can open it with Notepad on Windows or TextEdit on Mac.

Claude can also read other common formats, like Word, PDF, or spreadsheets, if you ask. Just say the name of the file you have.

CarlaHer script is in Word. She writes "read lesson-1-script.docx" instead of script.md.

2. The folder

In the Code tab, each session works in a folder on your computer. You choose that folder when you start a new session. Choose the project folder, where its files are.

How you choose it varies between app versions. If you can't find it, ask Claude in the Code tab: "how do I choose this session's folder in this app?". To check, ask: "what folder are you working in?".

Done whenClaude replies with the name of your project folder.

3. The path

spreadsheet-course/lesson-1/script.md means: inside the spreadsheet-course folder, in the lesson-1 folder, the script.md file. This is Carla's file path.

In your prompt, replace this path with the path to your file. If you don't know how to write the path, just say the file name and ask: "find this file in the project folder".

ExampleInstead of spreadsheet-course/lesson-1/script.md, you can write only the name of your file, like meeting-notes.docx.

05 · Practice: organize your project

Use one of your own projects instead of Carla’s course.

E1 · The project section

5 min

In the Code tab, open a session in one of your project folders and group its conversations into a section in the sidebar. If you can’t find where to create a section, ask Claude in the Code tab: "how do I create a section in the sidebar in this app?".

Done when: You can find your project conversations together in the sidebar within a few seconds, in a section with its name (if your app doesn’t show sections yet, the question above tells you what to do).

E2 · One task and two side questions

15 min

Run a task in the main conversation (Carla’s prompt, adapted). While it works or afterward, ask two questions in the side chat: Cmd + ; on Mac (Ctrl + ; on Windows) or /btw in the terminal.

Done when: You scrolled through the main conversation from beginning to end, and neither side question appears in it.

E3 · Two sessions side by side

10 min

Open a second session for another task in a different file, and put both in split view (Option + click on Mac, Alt + click on Windows). Then take one out of split view.

Done when: You saw both sessions in the same window, each saved its own file, and neither changed the other’s file.
